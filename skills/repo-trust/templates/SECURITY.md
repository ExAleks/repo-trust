## What is out of scope

- Vulnerabilities in dependencies — report them to the dependency's
  maintainers (we still want to know).
- Incidents that require an already-compromised machine or account.
- Social engineering.

## How to report

Do not open a public issue. Use the private channel:

1. GitHub → **Security** tab → **Report a vulnerability**.
2. Include: version or commit, environment, steps to reproduce, expected
   and actual behavior, and your assessment of impact.

We acknowledge reports within 7 days and aim to ship a fix within 30 days.
There is no bug bounty; credit in the fix description is offered if wanted.
